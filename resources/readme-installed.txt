　稽古 · 二十四史情境检索
═══════════════════════════════════════════════

【怎么用】

  双击桌面上的「稽古」图标（或开始菜单里的「稽古」）即可打开。

  1. 在输入框里写下令你困扰的现实处境，越具体越好
     （人物关系、时间压力、你已经做了什么）。
  2. 点「稽古一问」。
  3. 程序在本机检索史事（先秦到清），给出最相似的三条历史事件，
     每条包含五个部分：
         原文摘录 · 现代文翻译 · 核心人物 · 关键决策 · 最终结果
  4. 下面「鉴」的部分，是依据内置规则模板生成的分析、要避免的做法、
     可行动作。
  5. 点「看看引擎如何理解这句话」，可以看到本机是怎么分词、怎么扩展
     同义词、怎么给稀有词加权的。


【藏书阁】

  程序出厂只启用 201 则精选史事。安装包里另外带着二十四史全文
  （原文 + 白话译文，共 7.8 万则），默认不加载，需要时自己开。

  上方「藏书阁」页签里，每部史书一行，写着它的则数和占用的运行内存。
  勾选后立刻重载，下面的检索就按新语料来；取消勾选同样立刻生效。
  有「全选 / 全不选」两个按钮。

  默认只勾了《史记》，约 100 MB 运行内存。二十四史全勾约 1.4 GB ——
  内存吃紧就少勾几部。想回到出厂状态（只有 201 则精选），全部取消勾选即可。

  注意：勾的史书越多，前三条结果的构成越会变。词权重是按「当前已加载的
  全部语料」算出来的，这是按需加载的固有结果，不是故障。


【联网说明】

  所有检索、分析、建议都在你的电脑上完成，不调用任何 AI 接口。
  会联网的动作只有两件，都在启动后静默进行：
    1) 检查语料版本，只下载发生变化的史书 / 标签 / 停用词文件；
    2) 检查程序本体的新版本。有新版本时先在后台下载好，下载完了才问
       你要不要立刻重启更新；点「稍后」就下次再说，不影响使用。
  连不上网时自动用本地数据，不会弹错误提示。

  更新源地址写在程序目录下的两个纯文本文件里，改成自己的服务器也可以：
    update_base.txt   程序本体的更新源
    data_base.txt     语料的更新源（不填就跟随 update_base.txt）
  文件内容支持两种写法：
    github:owner/repo         从该仓库的 Releases 里取（出厂默认值）
    https://example.com/dir   从任意静态目录取；写成 file:/// 本地路径
                              也可以，便于离线测试


【自检】

  程序没有自检按钮，要自检得走命令行：在程序目录里打开一个命令提示符
  （地址栏输 cmd 回车即可），然后运行

      稽古.exe --selfcheck

  它会只读地检查一遍界面资源、语料载入、藏书阁分片、检索召回与更新清单，
  逐节打印结果，最后一行是 RESULT: SELFCHECK OK 或 SELFCHECK FAILED。
  不改动任何文件。


【万一网页界面起不来】

  程序不会卡在打不开的窗口上，会自动退到内置界面（长相一样、功能一样，
  检索结果还是同一套本地引擎算的），窗口标题会写「稽古 · 内置界面」。
  你也可以自己在「失败提示页」点「改用内置界面」按钮。

  想看看究竟出了什么事：程序目录下的 error.log 记录了完整原因
  （含出错位置与调用堆栈），把它发出来就能定位。

  只有一种情况需要联网：本机没有「Microsoft Edge WebView2 Runtime」时，
  程序会问你要不要装（约 2MB）。答「否」也没关系，照样能进内置界面。
  Windows 10 / 11 一般自带这个组件。


【怎么卸载】

  方式一：Windows「设置 → 应用 → 已安装的应用」里找到
           「稽古（二十四史情境检索）」，点「卸载」。
  方式二：在安装目录里双击「稽古-卸载.exe」。

  卸载会删除程序文件、桌面与开始菜单快捷方式；用户数据目录
  （%LOCALAPPDATA%\Jigu）也会一并清理。


【文件说明】

  稽古.exe                          主程序
  稽古-卸载.exe                      卸载程序
  Jigu-<版本>.ico                   图标（名字带版本号）
  corpus.json                       精选史事语料（201 则，外置，可热更新）
  corpus\                           二十四史分册（24 部 + 清单 index.json，
                                    藏书阁按需加载；卸载时一并删除）
  labels.json                       情境标签表（外置，可热更新）
  stopwords.json                    停用词表（外置，可热更新）
  data\                             史书数据（原始分册）
  data_version.json                 数据版本清单
  update_base.txt                   程序本体的更新源地址（可自行修改）
  data_base.txt                     语料的更新源地址（可自行修改）
  Microsoft.Web.WebView2.*.dll      界面渲染内核（随包附带）
  WebView2Loader.dll                内核加载器（随包附带）
  error.log                         出错时自动生成，用于排查
  使用说明.txt                       本文件
